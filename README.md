# Zomato — Customer Analytics

An interactive Excel analytics workbook built from the Zomato order dataset
(50,000 orders, ~5,000 customers, 200 restaurants). It answers the business
questions in the case study — revenue, customers, restaurants, coupons,
cancellations/refunds and churn — through live formula-driven tables, KPIs and
native Excel charts.

**Deliverable:** [`Zomato_Customer_Analytics.xlsx`](Zomato_Customer_Analytics.xlsx)

No macros are used. Everything runs on standard Excel formulas
(`SUMIFS` / `COUNTIFS` / `INDEX` / `IFERROR`) plus data-validation dropdowns,
so it opens cleanly in Excel 2021 / Microsoft 365.

---

## How to use it

1. Open `Zomato_Customer_Analytics.xlsx` in Excel.
2. Go to the **Dashboard** and pick values from the **FILTERS** row
   (City, Channel, Payment Mode, Order Status, Cuisine, Month).
3. Every KPI, key answer, table and chart across **all** sheets updates together.
4. On any **`— Charts`** sheet, use the drill controls at the top
   (City / Month / Cuisine / Channel / Payment / Status) to re-scope the whole
   workbook to a single value.
5. Set controls back to **`(All)`** to release them.

> Excel charts cannot detect a bar click, so drill-down is done with the
> dropdown controls above each chart sheet. They behave exactly like a
> click-through filter.

## Data & methodology

**Source:** `Zomato  Order Data.xlsx` — three sheets:
`Customer` (4,999), `Restaurants` (200), `Orders` (50,000).
Order timestamps span **01-Jan-2024 → 30-Apr-2026**.

**Definitions used**

- **Net revenue** = `order_amount − discount_amount`, counted only for
  **Delivered** orders (cancelled/refunded orders generate no realised revenue).
- **Gross order value** = sum of `order_amount` for all matching orders.
- **AOV** = total net revenue ÷ delivered orders.
- **Coupon order** = any order with `discount_amount > 0` (≈10% off).
- **Repeat customer** = a customer with 2 or more orders in the matching period.
- **Churn** = an active customer (≥1 order overall) with **no order in the last
  90 days** before the dataset cut-off (30-Jan-2026).
- **Revenue lost to churn** = lifetime net revenue historically generated by
  churned customers.

**Data cleaning / quality notes**

- One customer had city `' pune'` (leading space) — trimmed to `'Pune'`.
- 10 orders reference customer `C00001`, which is absent from the Customer
  master sheet. Those orders are **kept** and reported under
  name/city/channel `Unknown` (a placeholder master row was added so the
  lookup resolves).
